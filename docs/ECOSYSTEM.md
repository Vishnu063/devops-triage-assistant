# Optional ecosystem contract API

`triage.ecosystem` adds a standard-library-only integration interface while retaining the existing native collectors, catalog, approved repair engine and health policy. Ops Pilot orchestrates incidents and owns approval decisions; producers cannot grant approval. Basic diagnosis does not call a model. K8sGPT is an optional already-installed scoped read-only analyzer; the adapter never uses `--explain`, downloads a model or executes its output.

The ten v1.0 envelope types are DeploymentEvent, MonitoringAlert, Incident, Evidence, Diagnosis, RemediationProposal, ApprovalDecision, ExecutionResult, VerificationResult and IncidentReport. Every envelope has schema_version, type, id, source, service, correlation_id, timezone-aware timestamp and data. `python -m triage.ecosystem schema` prints the canonical JSON schema so producers can validate the wire format; it starts no service. `python -m triage.ecosystem validate --file event.json` checks a local event without sending it. `python -m triage.ecosystem diagnose --file event.json` produces evidence-referenced hypotheses and explains each suggested read-only command; it executes nothing.

`envelope()`, `validate()`, `diagnose()` and `verify()` are the reusable Python API. Existing collector findings/log-signature counts are reused. Raw application logs are not part of this contract. `verify()` accepts explicitly configured container, Kubernetes readiness, rollout, Prometheus and error-rate criteria plus the existing bounded HTTP health policy. Unknown required evidence is inconclusive; a command exit is never itself verification.

`python -m triage.ecosystem emit --file event.json --url http://127.0.0.1:8767/webhooks/ecosystem --outbox /private/outbox` sends one authenticated event using the token in OPS_PILOT_EVENT_TOKEN. It saves the event privately for failed-delivery recovery, retries transport failures at most twice, and reuses the original id. Keep tokens outside commands/Git. Only loopback HTTP or HTTPS is accepted; redirects, embedded credentials and unbounded payloads are refused. No paid API, broker, background process or other repository is required. Contract bounds are 64 KiB, depth 12 and 200 array items. These are single-owner integration controls, not a hostile-tenant isolation guarantee.

The caller must install this exact versioned package explicitly; no repository starts another component automatically. See the Ops Pilot ecosystem inventory/runbook for ownership, configuration, failure acceptance and current CI evidence. Optional K8sGPT requires explicit context/namespace and an installed binary; real cluster/provider validation remains separate from this package's deterministic tests.
